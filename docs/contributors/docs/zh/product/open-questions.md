# 开放问题

本文汇总尚未确定的产品决策。协作者不应将这些内容视为已经确定的实现要求。

## 专栏

- 摘要是否允许为空？
- 已发布作品被编辑撤稿后，应进入什么状态？
- 是否需要增加 `Archived` 状态？
- 各状态之间允许哪些转换？

当前后端撤稿后进入 `UNPUBLISHED`，并允许待审核之外的状态删除。
改变行为前需确认实现与产品目标之间的差异，参见[项目架构](../architecture.md)。

## 文集

- 多人协作作品加入文集后，除文集创建者之外的共同作者是否拥有管理权限？

## 搜索

- 搜索结果应提供哪些筛选项？
- 搜索结果应提供哪些排序方式？

## 社区帖

- 社区帖的具体长度限制是多少？当前暂定约为 `500` 词。

## 管理

- 举报由哪类角色处理？
- 分级处罚具体包括哪些等级和限制？
- 社区管理员是否需要启用？如果启用，其职责和权限是什么？

## 通知

后端已实现事件、收件人投递、提及、评论回复、已关注作者发布内容通知和已读状态。
前端尚无收件箱，参见[当前流程](../architecture.md)。以下产品策略及扩展触发条件仍待确定：

- 专栏审核通过、拒绝或被撤稿。
- 专栏或社区帖收到评论。
- 评论收到回复。
- 收到点赞或点踩。
- 新增关注者。
- 举报处理结果。

## 翻译

- 网站是否需要提供内置翻译功能？
